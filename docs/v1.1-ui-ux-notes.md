# PDF-Tailor v1.1 UI / UX 优化建议

## 1. 文档目标

这份文档用于整理当前版本界面和交互上的可改进点，重点聚焦：

- 提高使用效率
- 降低长时间使用的疲劳感
- 提升视觉完成度和产品感
- 减少学习成本和误操作

这里不讨论底层导出、旋转页兼容或数据模型问题，只关注当前界面层和用户交互层。

## 2. 当前界面判断

从当前实现看，产品的视觉方向已经基本成立：

- 有统一的暖纸张色系和工作台氛围
- 左中右三栏结构清晰
- 明暗主题已经接通
- 空态页、模态框、Toast 和缩略图卡片风格一致

当前最主要的问题不是“缺少样式”，而是以下几类：

- 信息层级偏平，很多操作看起来同等重要
- 控制项过多，高频操作和低频操作没有被明显分层
- 批量工具和参数卡片占据较大面积，压缩了核心内容区
- 长时间使用时，界面会有一点“密”和“吵”
- 桌面端已经像工具，但细节上还不够像正式产品

## 3. 当前版本的优点

### 3.1 整体视觉方向是统一的

当前使用了比较稳定的一组设计 token，见 [tailwind.config.ts](../tailwind.config.ts) 和 [index.css](../src/index.css)。

优点：

- 主色和辅助色有明确角色
- 深色模式不是简单反色，而是重新定义了暗色背景和边框
- 面板圆角、阴影和模糊效果统一

这说明后续工作应以“强化层级和节奏”为主，而不是彻底推翻现有风格。

### 3.2 主工作流已经可识别

用户从 [DropZone.tsx](../src/components/DropZone.tsx) 进入后，基本能理解：

1. 打开 PDF
2. 在中间裁剪
3. 左侧选页
4. 右侧调参数
5. 预览和导出

说明产品结构没有方向性错误，问题主要在细节组织。

### 3.3 反馈机制已经具备基础

当前已经有：

- Toast 反馈
- 导出进度
- 预览错误提示
- 旋转页和大文档提示
- Skeleton 和局部 loading 状态

这意味着下一步不需要从零补反馈，而是要把反馈变得更克制、更明确、更贴近上下文。

## 4. 主要 UI / UX 问题

### 4.1 头部过满，主次不清

[Header.tsx](../src/components/Header.tsx) 现在同时承载：

- 文档信息
- 打开 / 关闭
- 预览
- 导出
- 缩放
- 主题切换
- 语言切换

问题在于：

- 高频主操作和低频偏好设置混在一起
- 缩放按钮放在头部，会和工作区操作争夺注意力
- 头部视觉重量偏高，压缩了内容区的专注感

结论：

- 头部需要减负
- 主操作应更集中
- 偏好类入口应更收敛

### 4.2 左侧栏有点“功能堆叠”

[PageSidebar.tsx](../src/components/PageSidebar.tsx) 里把以下内容都放在缩略图上方：

- 批量选择说明
- 条件筛选
- 页码范围
- 批量清空

问题：

- 真正最重要的缩略图列表可视面积被占掉很多
- 页面一多时，视线要频繁穿过一大段操作区
- 常用和不常用的批量功能没有区分

结论：

- 左栏批量区应该折叠或分层
- 默认状态下应让用户先看到更多页面缩略图

### 4.3 右侧参数区阅读成本偏高

[PropertiesPanel.tsx](../src/components/PropertiesPanel.tsx) 现在包含：

- 文档状态
- 当前裁剪尺寸
- 模式切换
- 预设尺寸
- 定位方式
- 模板
- 数值边距
- 边距摘要
- 操作按钮

问题：

- 很多信息属于“编辑时参考”，却和操作按钮平铺在一列
- 高价值动作出现在滚动区底部，不够稳定
- 同一信息被展示多次，例如边距输入和边距摘要的关系比较松

结论：

- 右栏需要更明显的“摘要区 / 编辑区 / 操作区”分层
- 底部操作需要固定

### 4.4 中间工作区还不够“专注”

[Workspace.tsx](../src/components/Workspace.tsx) 的舞台感已经有了，但还可以更像“主画布”。

当前问题：

- 画布顶部工具和整体头部有部分重复
- 左右栏同时展开时，中间区仍然偏挤
- 没有“专注裁剪”的模式

结论：

- 中间区域应该是最强视觉中心
- 需要专注模式和更灵活的栏宽控制

### 4.5 缩略图卡片的信息有点吵

[PageThumbnail.tsx](../src/components/PageThumbnail.tsx) 的卡片目前会显示：

- 页码
- 旋转标签
- 已裁剪标签
- 已选中 / 就绪标签
- 缩略图或占位信息

问题：

- 低价值状态和高价值状态一起出现
- 标签数量一多，注意力容易从缩略图本身转移
- “Ready” 这类默认状态没有太大信息增量

结论：

- 应减少默认标签
- 保留异常和任务相关状态即可

### 4.6 模态框可用，但不够轻盈

[ExportDialog.tsx](../src/components/ExportDialog.tsx) 和 [PreviewModal.tsx](../src/components/PreviewModal.tsx) 已经具备完整功能，但还可以更舒服。

当前问题：

- 信息块略多，阅读节奏偏平均
- 关闭按钮、模式切换、辅助说明都在抢注意力
- 预览弹窗还不够像“核对结果”的工具，更像技术预览窗口

结论：

- 模态框内部也要强化层级
- 应把“主动作”和“说明信息”拉开

### 4.7 动效和反馈还有些“平均用力”

[index.css](../src/index.css) 中对所有 `panel-surface` 都加了进入动画。

问题：

- 多个面板同时入场时会有轻微“飘”的感觉
- 高频操作下，统一动画不一定真的让体验更高级

结论：

- 动效应该更克制、更有重点
- 优先给模态、首次载入和关键状态变化做动画

## 5. 最高优先级优化建议

### 5.1 头部减负

优先级：`P0`

建议：

- 头部只保留文档信息和主操作
- 主操作保留：
- 打开
- 预览
- 导出
- 次级入口收纳到菜单：
- 关闭文档
- 主题切换
- 语言切换
- 缩放控制移回工作区内部

预期收益：

- 头部更清爽
- 主路径更明确
- 中间区更有专注感

### 5.2 左侧批量工具折叠

优先级：`P0`

建议：

- 默认只显示：
- 已选页数
- 2 到 3 个高频快速筛选按钮
- 把页码范围和高级选择放进折叠面板
- 把“批量清空”做成危险操作样式，和筛选区分开

预期收益：

- 缩略图可视面积更大
- 侧栏扫描速度更快
- 页面多时压力明显降低

### 5.3 右侧操作栏固定

优先级：`P0`

建议：

- 顶部保留当前页信息和裁剪摘要
- 中段放模式、模板、边距编辑
- 底部操作区固定：
- 清除当前页
- 应用到选中页
- 应用到全部页

预期收益：

- 高频按钮始终可见
- 不需要滚到最底部才能执行下一步

### 5.4 中间工作区增加专注模式

优先级：`P0`

建议：

- 增加“隐藏左栏”“隐藏右栏”“只看画布”模式
- 支持临时全屏工作区
- 允许桌面端调节左右栏宽度

预期收益：

- 对精细裁剪和长文档调整帮助很大
- 更符合桌面工具使用习惯

## 6. 中优先级优化建议

### 6.1 缩略图信息减噪

优先级：`P1`

建议：

- 删除默认 `Ready` 状态标签
- 仅保留：
- 已选中
- 已裁剪
- 已旋转
- 拖拽排序改为显式拖拽手柄，不要整卡都可拖

预期收益：

- 页面列表更安静
- 点选和拖拽冲突更少

### 6.2 工作区增加常驻尺寸 HUD

优先级：`P1`

建议：

- 在画布区固定显示当前裁剪尺寸和单位
- 拖动时实时更新
- 松手后保留最终结果

预期收益：

- 精调时不需要频繁看右栏
- 中心区的反馈更直接

### 6.3 导出对话框更像“确认面板”

优先级：`P1`

建议：

- 把导出范围和导出模式改为更明确的主选择区
- 文件名输入放到次级信息区
- 进度状态展示更聚焦，不和其他控件竞争
- 记住上次导出模式和范围

预期收益：

- 重复导出更顺手
- 认知负担更低

### 6.4 预览弹窗增加核对能力

优先级：`P1`

建议：

- 增加页码输入跳转
- 支持左右键翻页
- 提供“原图 / 裁剪结果”快速对比
- 对被阻塞的 `Redraw` 给出更靠近切换按钮的说明

预期收益：

- 预览从“看一眼”升级为“可核对”

### 6.5 Toast 更克制

优先级：`P1`

建议：

- 错误才用强提醒
- 成功和普通信息降为更轻的提示样式
- 小屏时改顶部显示
- 避免多个提示连续堆叠遮挡内容

预期收益：

- 反馈更舒适
- 不会让界面显得持续处于告警状态

## 7. 长期舒适度优化

### 7.1 中文文本风格本地化

优先级：`P2`

当前很多标题样式仍偏英文设计习惯：

- 过多 `uppercase`
- 过密 tracking
- 很小的全大写标签

建议：

- 中文环境下减少无意义的全大写风格
- 让标题更自然、更像桌面工具，而不是展示页

### 7.2 字体栈补强

优先级：`P2`

[tailwind.config.ts](../tailwind.config.ts) 现在的字体栈更偏拉丁文字表现。

建议：

- 为中文优先环境补充更稳定的中文无衬线字体
- 保持英文标题字体的个性，但正文字体更注重阅读舒适度

### 7.3 动效分级

优先级：`P2`

建议：

- 面板首次出现时保留轻动画
- 高频刷新和切换时减少浮入动画
- 增加 `prefers-reduced-motion` 兼容

### 7.4 空态增加产品感

优先级：`P2`

[DropZone.tsx](../src/components/DropZone.tsx) 已经比早期版本好很多，但还可以继续补：

- 最近文件
- 三步上手说明
- 示例文档入口
- 快捷键提示

## 8. 建议落地顺序

建议按以下顺序推进：

1. 头部减负
2. 左栏批量区折叠
3. 右栏固定操作区
4. 中间工作区专注模式
5. 缩略图减噪和拖拽手柄
6. 导出弹窗和预览弹窗层级优化
7. Toast、字体、动效和空态抛光

## 9. 结论

当前版本已经具备不错的视觉基础，不需要大改风格。

真正值得做的是：

- 重新分配界面注意力
- 让高频动作更近
- 让低频设置更收敛
- 让中间工作区更像主角

如果只先做 3 项，建议优先：

1. 头部减负
2. 左栏批量区折叠
3. 右栏固定操作栏

这三项对使用舒适度、效率和产品感的提升最直接。
