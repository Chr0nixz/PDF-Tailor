# PDF-Tailor v1.0 发布清单

## 1. 版本目标

`v1.0` 的目标不是继续扩功能，而是以当前能力为基础，确认产品已经满足“可试用、可回归、可发布”的最低标准。

## 2. 当前状态总览

### 已完成

- [x] PDF 加载与页面渲染
- [x] 自由框选裁剪
- [x] 手柄缩放与吸附
- [x] 预设尺寸与边距输入
- [x] 多页缩略图与批量应用
- [x] 预览与导出
- [x] 撤销 / 重做和快捷键
- [x] 单元测试
- [x] E2E 冒烟测试
- [x] GitHub Actions CI
- [x] README 与实现文档

### 发布前仍需人工确认

- [ ] 在真实 GitHub 仓库中观察一次 CI 通过
- [ ] 做一轮人工发布验收
- [ ] 确认部署目标和发布方式
- [ ] 决定是否打 `v1.0.0` tag / release

## 3. 功能验收清单

### 文档加载

- [x] 可打开本地 PDF
- [x] 可渲染当前页
- [x] 可切换页面
- [x] 可缩放页面

### 裁剪编辑

- [x] 可拖拽创建裁剪框
- [x] 可移动裁剪框
- [x] 可通过 8 个手柄调整大小
- [x] 边缘和中心线吸附生效
- [x] 属性面板和画布实时联动
- [x] 可清除当前页裁剪

### 多页工作流

- [x] 左侧缩略图可导航
- [x] 支持多选页面
- [x] 可将当前页裁剪应用到选中页
- [x] 可应用到全部页

### 预览与导出

- [x] 可打开预览
- [x] 预览与导出走同一条导出管线
- [x] 支持 `Crop box`
- [x] 支持 `Redraw`
- [x] 非法裁剪会阻断导出
- [x] 旋转页风险会给出提示

## 4. 测试清单

### 自动化

- [x] `npm test`
- [x] `npm run build`
- [x] `npm run test:e2e`
- [x] CI workflow 已接入

### 建议人工回归

- [ ] 打开一个 2 页 PDF，完成裁剪、预览、导出
- [ ] 打开一个 100 页以上 PDF，观察缩略图滚动与预览表现
- [ ] 打开包含旋转页的 PDF，确认 `Redraw` 会被禁用
- [ ] 用外部 PDF 阅读器验证导出文件

## 5. 风险说明

### 当前接受的已知限制

- 旋转页 `Redraw` 尚未支持
- E2E 目前只覆盖 Chromium
- 导出暂未显示进度百分比

### 不应带入 v1.0 的阻断项

- [ ] 导出文件无法打开
- [ ] 批量应用破坏当前页或其他页状态
- [ ] 裁剪框坐标与最终导出结果明显不一致
- [ ] 主工作流 E2E 失败

当前代码库已经接近 `v1.0` 发布状态。

如果你准备正式发布，建议按下面顺序执行：

1. 在远程仓库触发并观察 CI
2. 做一次人工回归
3. 确认部署目标
4. 打 `v1.0.0` tag 并发布
